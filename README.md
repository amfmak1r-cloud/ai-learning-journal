## 日志

### 2026-10-03 · 第一天

**搞懂的概念**

- AI 是一栋四层楼：算力 → 大模型 → 应用 → Agent
- Agent 和大模型的区别不在聪明程度，而在「有没有手」
  - Agent = 大模型 + 工具 + 循环
- Git 是本地的时光机，GitHub 是云端的广场，两者不是一回事
- 仓库 = 文件夹 + 时光机 + README 说明书
- GitHub Copilot 和 GitHub 是两个不同的产品，不买 Copilot 也能用 GitHub
- Markdown 里按一次回车不算换行，必须空一整行才是新段落

**做过的事**

- 建成人生第一个仓库：ai-learning-journal
- 学会了在网页上编辑文件、上传文件、做 commit
- 踩了第一个坑：复制粘贴时换行全丢了
- 把仓库克隆到了自己电脑上，亲眼看到了 .git 时光机
- 学会了看懂 commit 历史

**下一步**

- 把仓库下载到本地，学会 git clone / add / commit / push 四个动作
